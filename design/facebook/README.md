# Facebook cover

`breeders-assistant-facebook-cover.png` is 1640 × 624 px, Facebook's recommended cover size, saved as PNG so the text stays sharp.

- Built from the app icon (rooster, duck and pigeon trio), the brand red and gold, and a real screenshot of the app.
- Text is Taglish: "Ang digital na katuwang ng bawat breeder." Features: pedigree and inbreeding check, 21-day hatch tracker, vaccine and health log, costs and suppliers. Install on phone, works without signal, free.
- Everything important is inside the centre 1110 px, so the phone crop doesn't cut it off. The lower left is left empty for the desktop profile picture. `crop-check.png` shows both views.
